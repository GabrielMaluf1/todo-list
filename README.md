# Painel de Estudos

Projeto simples feito com HTML, CSS e JavaScript para a Atividade Prática 2 de Git e GitHub. A página reúne lista de tarefas, bloco de notas e calculadora.

## O que a aplicação faz

- Adiciona tarefas com validação de texto vazio.
- Marca tarefas como concluídas.
- Remove tarefas individualmente.
- Filtra por todas, pendentes e concluídas.
- Limpa todas as tarefas concluídas de uma vez.
- Salva a lista no navegador com `localStorage`.
- Mostra contadores de tarefas totais e pendentes.
- Possui bloco de notas com salvamento automático.
- Possui calculadora com operações básicas e funções científicas.
- Permite escolher funções como raiz, potência, seno, cosseno, tangente, log, ln, fatorial, pi e Euler.

## Tecnologias usadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
